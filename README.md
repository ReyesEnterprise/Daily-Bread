🌅 Daily Bread

Hello World — and welcome!
Thank you for taking the time to visit my project. This is my first experience working with APIs, and it marks an exciting step forward in my journey as a developer.

Daily Bread is a simple and inspirational web app that fetches Bible verses using a public API and displays them in a clean, responsive layout.

//** some things to keep in mind **//

🚀 About This Project

This project was built to:
• Practice working with Fetch API
• Understand how HTTP requests and headers work
• Handle JSON responses
• Strengthen my JavaScript fundamentals
• Work with external data in real time

It represents my first hands-on experience integrating an external API into a live website.

📖 Features
• Retrieves Bible verses from a free public Bible API
• Displays inspirational scripture dynamically
• Responsive design (optimized for desktop, adaptable for tablets and mobile devices)
• Clean and minimal UI

🛠️ Tech Stack
• HTML
• CSS
• JavaScript
• Fetch API

💡 What I Learned
• How to send GET requests to an API
• How to handle JSON responses
• The importance of request and response headers
• Debugging CORS and network errors
• Structuring asynchronous code with .then()
